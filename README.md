## 📑 Coursework Overview

### 1. Assignments
- **CO1 - Assignment 1:** *Design and Develop a Complete Ethical-Hacking Engagement Framework for a University's Authorized Security-Assessment Programme (UEHEF).*
  - Scope definition, authorization policies, legal framework, threat modeling, lab environment rules, and responsible vulnerability disclosure.
- **CO2 - Assignment 2:** *Reconnaissance, Footprinting & Network Assessment.*
  - Target analysis, enumeration, and risk assessment strategies.

### 2. Lab Experiments (Kali Linux)
Detailed procedures and command references can be viewed in [Labs/README.md](Labs/README.md).

- **Experiment 1:** `rm`, `users`, `tree` — File deletion, user enumeration, and directory structures.
- **Experiment 2:** `less`, `more`, `vi` — Terminal-based file inspection and text editing.
- **Experiment 3:** `tree`, `head`, `tail` — Hierarchy visualization and viewing line ranges.
- **Experiment 4:** `ls`, `cat`, `mkdir` — Directory inspection, file creation, and concatenation.
- **Experiment 5:** `uptime`, `date`, `mv` — System diagnostics and file movement/renaming.
- **Experiment 6:** `touch`, `pwd`, `wget` — File creation, path inspection, and web payload fetching.
- **Experiment 7:** `cd`, `cp`, `ls` — Directory traversal, file duplication, and validation.

### 3. Project Presentation (`Team2.pptx`)
- **Project Title:** **LinkReveal**
- **Theme:** Decoupled, Privacy-First Mobile Security Tool for Cloud-Based Malicious URL Detonation and Phishing Analysis.
- **Supervisor:** Dr. Rajaram P.
- **Key Features:**
  - AI-driven URL expansion and reputation analysis using threat intelligence APIs (e.g. Google Safe Browsing).
  - Fault-tolerant redirect tracing mitigating firewall drops and server timeouts.
